# VinuHub .vc Domain Service

A decentralized .vc domain registration service on VinuChain, powered by a Solidity smart contract and a React + TypeScript frontend.

## Overview

This project allows users to:
- Register .vc domains (20,000 VC for ≤5 letters, 10,000 VC for >5 letters).
- Transfer tokens using domains.
- List and buy domains in a marketplace.
- View owned domains and transaction history.
